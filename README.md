# Habit Tracker 

## Features:

Allows the user to enter their habits through a form. They are able to add the planned start date and the frequency for this habit. The program then automatically creates the due date for each added habit.

Allows the user to log their completion of the habit, with the time of logging being used as that habit's completion date. The program then automatically creates the subsequent habit using the frequency data associated with it.

The user is able to view streak information regarding their tracked habits, including optimal completion times and completion rates, which are dynamically updated based on each user's habit completion statistics.

Should a user's habit needs change, or their input was wrong, they are able to directly edit the stored data.

The data stored in the program does not save on exit, and must be exported through use of the 'Save Data' button.
